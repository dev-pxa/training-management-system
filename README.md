# 培训管理系统

基于 Umi Max + Ant Design Pro 构建的培训管理系统。

## 功能模块

系统包含以下主要模块：

### 1. 人员管理

- 用户列表：展示所有用户信息，支持按名称、手机号、用户名、权限筛选
- 用户详情/编辑：新增或编辑用户信息，包含姓名、手机号、用户名、权限等字段
- 权限说明：权限字段使用数字表示（0-用户，1-管理员）

### 2. 课程管理

- 课程列表：展示课程信息，支持按课程名称、类型、是否需要考试等条件筛选
- 课程类型：微课程、系列课程
- 课程详情/编辑：包含课程名称、简介、类型、章节列表、是否需要考试、证书配置等
- 章节管理：支持新增、删除章节，每个章节包含名称、描述、内容资源

### 3. 资源管理

- 资源列表：展示所有资源文件，支持按名称、资源类型、拥有者筛选
- 资源类型：图片资源（png、jpg、jpeg）、视频资源（mp4、mov）、PDF 资源（pdf）
- 资源详情/编辑：支持拖拽上传，限制文件格式和大小
- 文件大小限制：图片/PDF 最大 20MB，视频最大 100MB

### 4. 测试管理

- 测试列表：展示所有测试试卷
- 测试详情/编辑：支持选择题和填空题两种题型
- 题目管理：可动态添加、删除题目和选项

## 技术栈

- **框架**：Umi Max
- **UI 组件**：Ant Design Pro
- **语言**：TypeScript
- **状态管理**：Umi Max 内置 model

## 路由说明

| 路径                   | 说明          |
| ---------------------- | ------------- |
| `/user`                | 人员管理列表  |
| `/user/add`            | 新增用户      |
| `/user/detail/:id`     | 用户详情/编辑 |
| `/course`              | 课程管理列表  |
| `/course/add`          | 新增课程      |
| `/course/detail/:id`   | 课程详情/编辑 |
| `/resource`            | 资源管理列表  |
| `/resource/add`        | 新增资源      |
| `/resource/detail/:id` | 资源详情/编辑 |
| `/test`                | 测试管理列表  |
| `/test/add`            | 新增测试      |
| `/test/detail/:id`     | 测试详情/编辑 |

## 权限说明

系统使用权限位控制访问：

- `0` - 普通用户
- `1` - 管理员

管理员可访问所有模块，普通用户权限请参考具体业务配置。

## 资源上传接口文档

后端需实现以下文件上传接口：

### 上传资源文件

- **请求方式**：POST
- **请求路径**：`/api/upload`
- **请求格式**：`multipart/form-data`
- **请求参数**：
  - `file`: 文件对象
- **响应格式**：
  ```json
  {
    "code": 0,
    "des": "success",
    "data": {
      "url": "文件访问URL"
    }
  }
  ```

### 资源类型映射

| 类型值 | 类型名称 | 允许格式       |
| ------ | -------- | -------------- |
| 0      | 图片资源 | png、jpg、jpeg |
| 1      | 视频资源 | mp4、mov       |
| 2      | PDF 资源 | pdf            |
